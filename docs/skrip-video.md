# Skrip Video Pitching (2–3 minit)

Keperluan: MP4/MOV atau pautan Google Drive/YouTube ("Anyone with the link"). Kandungan: isu, cadangan inovasi, dan demonstrasi awal prototaip.

| Masa | Visual | Skrip (BM) |
|---|---|---|
| 0:00–0:20 | Klip Ipoh / stesen ETS | "Tahun lepas, 10.4 juta pelancong domestik bermalam di Perak. Tetapi ketibaan pelancong antarabangsa jatuh 1.5%, dan ramai pelancong hanya singgah sebelum bermalam di Pulau Pinang atau KL." |
| 0:20–0:40 | Peta: Padang Besar, JB Sentral, Ipoh | "Masalahnya bukan Perak tidak menarik. Masalahnya ialah akses dan tempoh menginap. Penerbangan ke Ipoh terhad, tetapi kereta api ETS sudah menghubungkan sempadan Thailand dan Singapura terus ke Ipoh." |
| 0:40–1:00 | Logo SinggahPerak | "Kami perkenalkan SinggahPerak: pakej pelancongan berasaskan kereta api untuk pelancong serantau, dengan sekurang-kurangnya satu malam di Perak." |
| 1:00–1:50 | **Rakaman skrin:** pilih Thailand, 3H2M, Warisan; tukar bahasa ke Thai; tekan Tempah | "Pelancong dari Hat Yai memilih tempoh dan minat. Pelan disusun mengikut masa ketibaan ETS, dalam bahasa mereka sendiri. Setiap aktiviti menunjukkan peniaga kampung yang mendapat manfaat. Mereka boleh membayar menggunakan aplikasi bank sendiri melalui DuitNow QR." |
| 1:50–2:20 | **Rakaman skrin:** papan pemuka dikemas kini secara langsung | "Bagi kerajaan negeri, setiap tempahan masuk ke papan pemuka: purata malam di Perak, perbelanjaan mengikut daerah, dan peratus yang sampai kepada komuniti." |
| 2:20–2:45 | Ringkasan impak | "Kos rendah, kerana kereta api dan DuitNow QR sudah wujud. Kami mahu merintis bersama peniaga di Kinta dan Kuala Kangsar, dan bersedia untuk pembukaan RTS Link pada 2027." |
| 2:45–3:00 | Logo + tagline | "SinggahPerak: jangan sekadar singgah, bermalamlah di Perak." |

**Tip:** Rakam skrin dalam resolusi 1080p. Sediakan sari kata BM/Inggeris. Pastikan suara jelas.
